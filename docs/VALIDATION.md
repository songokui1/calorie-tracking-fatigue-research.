# Validation and limitations

- Python source syntax checks do not establish that the end-to-end study succeeds.
- Reddit API availability, community rules, data coverage, and API credentials can change.
- A rolling five-year window makes reruns time-dependent.
- Balanced subreddit/year caps improve distribution across sampled strata but do not produce a representative sample of all Reddit users.
- The baseline embedding and sentiment measures are exploratory indicators.
- LLM first-pass coding followed by model-based audit is **not** equivalent to independent human coder agreement.
- Validate coding decisions and quoted evidence manually before making publication claims.
- Raw exports and run artifacts should remain outside the public repository pending research-ethics review.
